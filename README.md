# SS-StyleS PWA

スマートフォン向けスプラッシュスクリーン演出サンプル集

## 概要

SS-StyleS（Splash Screen Styles）は、スマートフォン専用のPWAアプリケーションです。21種類の美しいスプラッシュスクリーンアニメーションを全画面で体験できるポートフォリオアプリです。

## 特徴

- **21種類のアニメーション**: ベース技術10種 + 組み合わせ技術11種
- **スマートフォン専用**: 375px幅で最適化（iPhone基準）
- **PWA対応**: ホーム画面にインストール可能
- **フルスクリーン体験**: タッチで即座にフルスクリーン表示
- **60fps**: GPU加速による滑らかなアニメーション
- **スクロール位置保持**: アニメーション後も元の位置に復帰

## アニメーション一覧

### ベース技術（1-10）
1. ミニマルフェード - 大きなロゴがフェードイン
2. グラデーション波 - 画面を横切る美しいグラデーション
3. パーティクル爆発 - 中央から放射状にパーティクル散布
4. タイポグラフィ - 大文字が順次表示
5. 液体モーフィング - 大きな流体形状の変化
6. ネオン回路 - 光る回路パターンが画面に展開
7. 3Dキューブ - 立体キューブが画面中央で回転
8. オーガニック - 自然な有機的形状が変化
9. グリッチ - 画面全体にデジタルノイズ
10. 線描アニメーション - 線が文字/図形を描く

### 組み合わせ技術（11-21）
11. グラデーション × パーティクル
12. タイポグラフィ × フェード × スケール
13. 液体モーフィング × グラデーション
14. 3D × ネオン × 回転
15. ミニマル × 線描 × 微細パーティクル
16. オーガニック × 液体 × カラー変化
17. グリッチ × タイポグラフィ × ネオン
18. 線描 × フェード × グロー
19. パーティクル × 3D × グラデーション
20. ネオン × 線描 × モーフィング
21. タイポグラフィ × グリッチ × パーティクル

## 技術仕様

- **フレームワーク**: React 18 + TypeScript
- **ビルドツール**: Vite
- **PWA**: Service Worker + Web App Manifest
- **スタイル**: Pure CSS (CSS Variables + Animations)
- **対応画面**: 375px〜430px幅（スマートフォン専用）

## 開発・ビルド

```bash
# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev

# 本番ビルド
npm run build

# プレビュー
npm run preview
```

## PWA機能

- **オフライン動作**: 初回読み込み後は完全オフライン
- **ホーム画面追加**: アプリアイコンでアクセス可能
- **フルスクリーン**: 没入感のあるアニメーション体験

## パフォーマンス

- **初回読み込み**: 2秒以内
- **アニメーション**: 60fps維持
- **GPU加速**: transform3d使用
- **メモリ効率**: 自動クリーンアップ
